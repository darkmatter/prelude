# Acme guide

This page ships inside the app: `main.ts` imports it as text, so the
single-file build carries it too.

## Everyday commands

- `dev --port 8080` starts the server on another port.
- `db:migrate --dry-run` shows the migration plan without applying it.
- `db:seed` loads sample rows.

Run the app with no arguments to pick a command.
